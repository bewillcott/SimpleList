# SimpleList

This program is the result of a YouTube video: [Master C++ on Linux](https://youtu.be/VXvPpPCF7E0?si=issGRLX0UhEb0DkT) by [SavvyNik](https://www.youtube.com/@SavvyNik).

Since the course completed, I have been 'improving' the code. Not because the course was incomplete, but because I tinker. I'm always trying to improve on code, whilst I learn what is and isn't possible for me to achieve.

If you are contemplating on learning C++, then I highly recommend SavvyNik's video. Once you have been through his video, then maybe have a look at the results of my tinkering.

Have a great day (or night).
Brad.

---

In-case you are interested, this program was developed using Visual Studio Code.

The formatting was done by the [Clang-Format](https://clang.llvm.org/docs/ClangFormat.html) extension, installed into VS Code.
